# embeddings/

Contains precomputed vector files generated by `build_embeddings.py`.

**Gitignored** — do not commit these (vectors.npy can be 30MB+).

## Files

| File | Shape / Type | Description |
|---|---|---|
| `vectors.npy` | `(N, 384)` float32 | L2-normalised sentence embeddings, one per paper abstract |
| `ids.npy` | `(N,)` string | ArXiv paper IDs, same order as vectors |
| `titles.npy` | `(N,)` string | Paper titles, same order as vectors |
| `hnsw_index.pkl` | pickle | Cached HNSWIndex object — built once by `search.py`, reused on subsequent runs |

## Why L2-normalised?

`build_embeddings.py` passes `normalize_embeddings=True` to sentence-transformers.
This means every vector has magnitude 1 (lies on a unit hypersphere).

Consequence: `dot_product(a, b) == cosine_similarity(a, b)` for all pairs.
So searching by cosine distance and searching by dot product give identical
rankings — and dot product is cheaper (no norm division needed). Many
production vector DBs exploit this to skip the normalisation step at query time.

Generated by running:
```bash
python semantic_search/build_embeddings.py
```
